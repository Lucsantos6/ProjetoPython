## Mini Sistema de Vendas em Python

## Descrição
Este projeto é um mini sistema de vendas desenvolvido em Python, com foco no aprendizado de conceitos fundamentais da linguagem. O sistema permite o gerenciamento básico de vendas utilizando funções, loops, estruturas condicionais e tratamento de dados.

##  Objetivos
- Praticar a lógica de programação em Python

- Utilizar funções para modularização do código

- Aplicar estruturas de repetição e decisão

- Manipular dados de forma simples e eficaz

- Criar uma base para sistemas mais completos no futuro.

## Funcionalidades
- Cadastro de produtos

- Registro de vendas

- Consulta de produtos cadastrados

- Relatório de vendas realizadas

- Cálculo de total vendido.

## Tecnologias Utilizadas
- Python 3.x

## Aprendizados
Durante o desenvolvimento deste projeto, aprofundei meus conhecimentos em diversos conceitos essenciais da programação com Python, incluindo:

- Declaração e uso de funções para tornar o código mais modular e reutilizável

- Estruturas de repetição como for e while, fundamentais para percorrer listas e manter o sistema em execução contínua

- Condicionais (`if`, `elif`, `else`) para controlar o fluxo do programa de acordo com diferentes situações

- Manipulação de listas e dicionários para armazenar e organizar os dados de produtos e vendas

- Entrada e saída de dados com o terminal, permitindo interação com o usuário de forma simples

- Tratamento de erros para evitar falhas durante a execução e tornar o sistema mais robusto
